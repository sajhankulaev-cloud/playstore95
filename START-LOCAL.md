# Локальный запуск PlayStore 95

1. Установите Node.js 22 LTS или 24 LTS с npm.
2. Распакуйте архив. Откройте терминал в папке playstore95-main, рядом с файлом package.json.
3. Установите зависимости и запустите сервер:

```sh
npm ci
npm start
```

Откройте http://localhost:3000 в браузере. Для остановки нажмите Ctrl+C в терминале. При следующем запуске достаточно команды npm start из той же папки.

Каталог уже находится в папке data. Изменения локальной базы сохраняются в этой папке. Для установки зависимостей, загрузки новых изображений, просмотра трейлеров и обновления данных из PS Store требуется интернет.

Для функций админки, которые запускают браузер (например, генерации скриншотов), выполните из той же папки:

```sh
npx playwright install chromium
```
